# 证据编排式报告：组长审阅框架

比赛版不调用大模型。系统只根据用户填写的业务条件、已收录法规和预先审阅的条件分支形成报告；没有证据的内容进入“资料缺口”，不写成法律结论。

## 输入

- 目标国家、产品名称和补充说明
- 产品类别、企业角色、销售渠道、贸易方向、消费者用途

## 形成过程

1. **读取事实**：保留已填写信息，未知字段不做推断。
2. **选择路径**：消费者用途、线上销售、供应链角色、进口申报、产品特征和专项法规边界分别触发相应核查路径。
3. **绑定证据**：每个条件性事项绑定收录法规的具体条款；BERTopic 只推荐补充阅读，不用于判断适用性。
4. **输出报告**：按优先顺序展示摘要、核查事项、下一步、材料、法条依据、待补信息和报告边界。

## “德国出口弯头管件”示例框架

| 报告区块 | 会输出什么 |
| --- | --- |
| 已知事实 | 目的地德国；产品为弯头管件；未填写的材质、压力、接触介质和进口商明确标注为未知。 |
| 首要核查 | 管件材质、口径、额定压力、介质、安装位置和最终用途；这些事实决定后续专项法规及归类路径。 |
| 进口路径 | 若货物从欧盟外进入，则提示核查申报主体、合同发票、商品归类和原产地支持材料，并链接海关法典条文。 |
| 专项法规边界 | 不把管件自动认定为建筑、承压设备、机械零件或消费品；未收录的专项法规和德国国内要求列为资料缺口。 |
| 可执行结果 | 一份按优先级排列的材料清单和待补问题，可继续打开英文原文并沿明确引用追溯。 |

## 可演示的差异

- 同一产品从“线上、面向消费者”改为“线下、仅专业用途”时，线上商品页面和一般消费品路径会退出。
- 从“欧盟以外进入”改为“欧盟内部流通”时，申报主体、归类和原产地核查路径会退出。
- 产品由“弯头管件”改为“电热水壶”时，系统提示收集电压、功率和电路资料，并将专项法规与 CE 作为待补的核查路径，而不是直接给出认证结论。

## 边界

当前语料仅包含四部欧盟层级原始公布文本，共 428 条正文。没有德国国内法、完整附件、产品专项法规、实时税率或个案合规结论。报告用于提出可验证的核查任务，不是法律意见。
